Nihongo Mock Logo Assets

Files:
- nihongo-mock-logo.svg  Transparent, scalable horizontal logo for website headers (recommended).
- nihongo-mock-logo.png  Transparent high-resolution PNG (1800 x 440).
- nihongo-mock-icon.svg  Square icon for favicon/app icon use.
- nihongo-mock-icon.png  Transparent PNG icon (512 x 512).

Website usage:
1. Copy the SVG or PNG file into your website's public/images directory.
2. Use in HTML/React:
   <img src="/images/nihongo-mock-logo.svg" alt="Nihongo Mock" />

For a favicon, use nihongo-mock-icon.svg or nihongo-mock-icon.png.
